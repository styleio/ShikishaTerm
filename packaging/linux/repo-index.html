SHIKISHA-TERM

The runtime with no window, for a machine you reach from a browser.

Debian / Ubuntu

curl -fsSL @BASE@/shikisha-archive-key.asc \
  | sudo tee /etc/apt/keyrings/shikisha.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/shikisha.asc] @BASE@/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/shikisha.list
sudo apt update && sudo apt install shikisha

Fedora / RHEL / openSUSE

sudo rpm --import @BASE@/shikisha-archive-key.asc
sudo tee /etc/yum.repos.d/shikisha.repo <<'REPO'
[shikisha]
name=SHIKISHA-TERM
baseurl=@BASE@/rpm
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=@BASE@/shikisha-archive-key.asc
REPO
sudo dnf install shikisha

Anywhere else

One static binary, installed into your own home folder. No root, nothing else on the machine touched.

curl -fsSL https://raw.githubusercontent.com/styleio/ShikishaTerm/main/packaging/linux/install.sh | sh

Then

Installing does not start anything. When you want it running:

systemctl --user enable --now shikisha
loginctl enable-linger "$USER"   # keep it running after you log out

It prints the address to open the board at, and writes it to the log beside its settings.
