## Two steps to a running tab

1. **Press Get in the Store, then open it.** Nothing else to set up — the Store installs it
   and keeps it up to date on its own.
2. **Follow the pointers on screen.** "Getting set up" opens first and asks which AI you
   work with. Then the board points at the PROJECT heading — **"Start by adding a
   project"** — and its `+` asks for the folder you work in. Press the `+` the next
   pointer shows, and an AI starts in that folder. There is no JSON to edit.

From there, [the manual](/manual/) is four pages, and [automation](/automation/) is where
agents start handing work to each other.
