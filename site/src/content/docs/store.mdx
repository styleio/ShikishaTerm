## Two steps to a running tab

1. **Press Get in the Store, then open it.** Nothing else to set up — the Store installs it
   and keeps it up to date on its own.
2. **Press `[e]`.** A terminal tab is already there; the settings screen opens inside the
   window, and you pick which AI runs in which folder. There is no JSON to edit.

From there, [the manual](/manual/) is four pages, and [automation](/automation/) is where
agents start handing work to each other.
