## 起動までの3手順

1. **好きな場所に展開します。** フォルダーでも USB メモリでも構いません。
   インストールは発生しないので、フォルダーごと消せばきれいに消えます。
2. **`SHIKISHA-TERM.exe` を実行します。** ここで初回だけ Windows が
   **「WindowsによってPCが保護されました」** と出して、「実行しない」しかボタンを
   見せません。**詳細情報 → 実行** で進めます。2回目からは出ません。これは SmartScreen の
   画面で、zip に証明書が付いていないから出ます。ファイルから何か見つかったわけでは
   ありません。
3. **`[e]` を押します。** 設定画面がウィンドウの中で開き、どのフォルダーでどのAIを
   動かすかをそこで選べます。JSON を書く必要はありません。

続きは[手引き](/ja/manual/)（4ページ）と、[自動化](/ja/automation/)。
AI同士に仕事を渡し合わせるのは自動化のほうです。

落としたものを確かめたいときは `Get-FileHash .\SHIKISHA-TERM.zip -Algorithm SHA256` を実行して、
同じビルドが書いた
[SHIKISHA-TERM.zip.sha256](https://github.com/styleio/ShikishaTerm/releases/latest/download/SHIKISHA-TERM.zip.sha256)
と見比べてください。
