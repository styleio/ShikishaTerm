## 初回に Windows が1度だけ止めます

最初に実行したとき、Windows が **「WindowsによってPCが保護されました」** と出して、
「実行しない」しかボタンを見せません。**詳細情報 → 実行** で進めます。2回目からは出ません。

これは SmartScreen の画面で、zip にコード署名証明書が付いていないから出ます。
ファイルから何か見つかったわけではありません。配布物はタグ付きコミットから
GitHub Actions が公開の場で作っています。

この画面に会いたくなければ、[Microsoft Store 版](https://apps.microsoft.com/detail/9PB8XQVM87Z0)
が同じ中身で、Microsoft の署名付き・自動更新付きです。

## 中身を確かめたいとき

```powershell
Get-FileHash .\SHIKISHA-TERM.zip -Algorithm SHA256
```

zip を作ったのと同じビルドが書いた
[SHIKISHA-TERM.zip.sha256](https://github.com/styleio/ShikishaTerm/releases/latest/download/SHIKISHA-TERM.zip.sha256)
と見比べてください。

## 起動までの3手順

1. **好きな場所に展開します。** フォルダーでも USB メモリでも構いません。
   インストールは発生しないので、フォルダーごと消せばきれいに消えます。
2. **`SHIKISHA-TERM.exe` を実行します。** ターミナルのタブが1つ開いた状態で始まります。
3. **`[e]` を押します。** 設定画面がウィンドウの中で開き、どのフォルダーでどのAIを
   動かすかをそこで選べます。JSON を書く必要はありません。

続きは[手引き](/ja/manual/)（4ページ）と、[自動化](/ja/automation/)。
AI同士に仕事を渡し合わせるのは自動化のほうです。

## ひとつだけお願いがあります

zip から先ほどの警告を消すには、コード署名証明書が要ります。
[SignPath Foundation](https://signpath.org/) はオープンソースに無償で発行していますが、
その前に「外から確かめられる評判」を求めます。GitHub のプロジェクトでいちばん分かりやすい
その形が、スターです。

使えそうだと思われたら、**[GitHub でスターを付けてください](https://github.com/styleio/ShikishaTerm)**。
1秒で終わって、しかも通りすがりの人にできることの中では、署名付きの配布にいちばん近づく
行為です。あなたの次に zip を落とす人のためにもなります。
