## AIが4体。窓が4つ。どれが待っているのか分からない。

ターミナルのAIを1体動かすのは簡単です。4体になると途端に破綻します。

AIの数だけ窓が増え、止まっている1つを探してAlt+Tabを繰り返し、結果を手でコピペして回る
ことになります。10分前に終わったAIは終わったまま座っていて、こちらがたまたま覗くまで
気づけません。

**SHIKISHA-TERM は画面を読んで教えます。** どのタブも「**作業中**」「**完了**」
「**あなた待ち**」のどれかを示します。ツールが実際に出力した文字から判定するので、
特定の会社のAPIではなく、どのコマンドラインツールでも同じように働きます。

<img src="/desktop.png" alt="SHIKISHA-TERM — 複数のAIを1つの窓に並べ、各行が作業中・完了・あなた待ちのどれかを示している画面" style="width:100%;border-radius:12px;margin-top:1.2em" />

## 本当に面倒なのは、受け渡しの方

どれが待っているかが分かるのは半分です。残り半分は、**自分が運び屋をやめること**。

一度だけ言っておけば——「これが終わったら結果をレビュー用のタブへ」——あとは勝手に
起きます。Lua で書いてもいいし、普通の言葉で説明して、すでに入れてあるAIに書かせても
構いません。

## AIは「どこで」働いているのか

自分がどこにいるか分かっていないAIは、平気で別のプロジェクトを書き換えます。

タブは**作業フォルダ**ごとにまとまります。ブランチに専用のフォルダを与えれば、それを
担当するAIはそこから出ません。**gitパネル**は端末が出る場所にそのまま開きます——
ファイル単位ではなく**その一部だけをステージ**でき、同じパネルの裏側が履歴で、
コミットメッセージは自分で書いても書かせてもよく、コンフリクトはAIに解きほぐさせて
**判断だけ人間がします**。

QRコードを読むだけで、どのタブが何をしているかが見え、指示も送れます——電車の中でも、
カフェでも、寝床からでも。[Tailscale](https://tailscale.com/) 越しなら、届くのは
自分の端末だけ。暗号化されたまま、どこからでも。

## はじめかた

1. **[Microsoft Store から入れる](https://apps.microsoft.com/detail/9PB8XQVM87Z0)**。
   あるいは[持ち運べる版](https://github.com/styleio/ShikishaTerm/releases/latest)を
   好きな場所に展開する（USBメモリでも動きます）。
2. 起動する。端末のタブが最初から1つ開いています。
3. `[e]` を押す。設定画面が**窓の中に**開くので、どのAIをどのフォルダで動かすかを選ぶ。
   JSONを書く必要はありません。

## 最初によく訊かれること

<details>
<summary><strong>APIキーは要りますか？</strong></summary>

要りません。すでにインストールしてログイン済みのコマンドラインツールを、あなたが
契約しているサブスクのまま動かします。キーは保存もしませんし、要求もしません。
</details>

<details>
<summary><strong>Claude Code や Codex の代わりになるものですか？</strong></summary>

いいえ、**それらを動かす側**です。ログインも設定も履歴もそのままの場所に残ります。
明日新しいCLIが出たら、タブをそれに向ければ済みます。
</details>

<details>
<summary><strong>Windows だけですか？</strong></summary>

現時点では、はい。クロスプラットフォームの薄い層ではなく、Windows の疑似コンソール
（ConPTY）の上に作ってあります。SSH・WSL・IME入力・レガシーな文字コードが
Windows で素直に動くのは、そのためでもあります。
</details>

<details>
<summary><strong>どこかに何か送りますか？</strong></summary>

既定では何も送りません。アカウントもなく、こちらのサーバーも存在しません。通信は
あなたが設定したときだけ起き、相手はあなたが選んだ先です——キーを入れたAIの提供元、
登録したWebhook、あるいは自分のスマホ。全部
[プライバシーポリシー](/ja/privacy/)に並べてあります。
</details>

<details>
<summary><strong>ターミナルですか、IDEですか？</strong></summary>

ターミナルです。gitパネルもブラウザもありますが、それはAIがそれらを必要とするからで、
エディタになろうとしているわけではありません。
</details>

<details>
<summary><strong>Store版と zip、どちらを選べば？</strong></summary>

Store版は Microsoft が署名しているので警告が出ず、更新も自動です。zip は同じビルドを
何もインストールせずに使うもの——展開して起動し、フォルダごと消せば跡が残りません——
ただし署名が無いぶん、**Windows が初回に一度だけ警告を出します**。どんな警告で、
どうすれば消えるのかは下に書いてあります。
</details>

## zip に出る警告と、それを消す方法

展開した zip を初めて起動すると、Windows が「**WindowsによってPCが保護されました**」と
出します。SmartScreen です。**何も知らされずに出ると、正直かなり怖い**ので先に書いて
おきます——**出るのが正常**で、「**詳細情報**」→「**実行**」で進めます。これはファイルに
問題があるからではなく、zip にコード署名の証明書が付いていないからです。配布物はすべて
公開の GitHub Actions がタグ付きコミットからビルドしていて、ダウンロードの隣に SHA256 を
置いてあるので、受け取ったバイト列がビルドされたものと同一かを自分で確かめられます。

**Store版ではこの警告は出ません**——Microsoft が署名しているからです。

zip からもこれを消すには、コード署名の証明書が要ります。
[SignPath Foundation](https://signpath.org/) はオープンソースに無料で発行していますが、
このような実行ファイルに対しては、自分たちの名前で証明書を出す前に
*「a certain verifiable reputation（一定の、検証可能な評判）」* を求めています。
GitHub のプロジェクトにとって、その評判のいちばん見える形が**スター**です。

**この道具が役に立つなら、[GitHub でスターを付けてください](https://github.com/styleio/ShikishaTerm)。**
通りすがりの人が1秒でできて、署名付きビルドの実現に最も近づくことです——あなたの次に
zip を落とす人のために。
