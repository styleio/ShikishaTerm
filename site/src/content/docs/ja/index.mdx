## AIたちを同じ部屋に集めて議論させる

**Claude・Codex・Gemini・DeepSeek に一つのお題を討論させたり**、1つに実装させて他に
レビューさせたり。審判が総括し、そのやり取りは**「結果」タブにチャット形式で描画**され、
全記録を**ワンクリックでMarkdownダウンロード**できます。

内部エンジンは同じで、討論もコードレビューもブラウザ操作も、すべて後から読める
トランスクリプトとして残ります。

## 外出先からスマホで、AIの様子を見て「続きをやっといて」

QRコードを読むだけで、全タブの状況を見て指示を送れます。電車の中でも、カフェでも、ベッドからでも。
[Tailscale](https://tailscale.com/)（無料）を入れておけば、暗号化された経路で
**自分の端末だけ**がどこからでも繋がります。

## なぜ作ったか

ターミナルのAIを1つ動かすのは簡単です。**4つ**動かすと途端に破綻します。

ウインドウがAIの数だけ増え、どれが自分の返事を待っているのか分からなくなり、
結果を手でコピペして回ることになります。SHIKISHA-TERM は
**処理中 / 完了 / 確認待ち** を区別できるターミナルで、AI同士で仕事を渡すこともできます。

ターミナルで動くものなら何でも扱えるので、特定のベンダーに縛られません。
Claude Code、Codex CLI、Gemini CLI、DeepSeek、Ollama、Aider、SSH越しの素のシェルも同じように扱えます。

## 使いはじめ

1. [Releases](https://github.com/styleio/ShikishaTerm/releases/latest) からzipを落として
   好きな場所に展開（USBメモリでも同期フォルダでも動きます）
2. `SHIKISHA-TERM.exe` を起動
3. `[e]` を押すとブラウザで設定画面が開くので、どのAIをどのフォルダで動かすか決める

<img src="/settings.png" alt="SHIKISHA-TERM 設定画面 — タブ（名前・コマンド／SSH・作業フォルダ・自動化）をフォームで設定、JSON編集不要" style="width:100%;border-radius:12px;margin:.4em 0 1em" />

そのフォルダの外には何も書きません。

:::note[向き・不向き]
**今のところWindows専用**です（ConPTYの上に作っているため）。
**CLIを置き換えるものではなく、動かすもの**なので、手持ちのサブスク・ログイン・設定は
そのままで構いません。そしてIDEではなくターミナルです。
:::
