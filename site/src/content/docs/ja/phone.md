出かけている間に終わったAIは、席に戻ったときには「10分前に終わっていた」状態です。
スマホからの画面は、そこへの答えです。どのタブが何をしているかが一覧で見えて、
その場で指示を返せます。

段階は3つあって、どこで止めても構いません。

<img src="/phone.png" alt="スマホで見た SHIKISHA-TERM。複数のAIが並び、それぞれ作業中・待機中・完了が分かる" style="display:block;margin:1.4em auto;width:320px;max-width:100%" />

## 1. 同じWi-Fiの中だけ ── 何も入れずに使えます

設定を開いて「スマホ」の項目にある **外出先やスマホから、状況の確認と指示ができる
ようにする** をオンにします。QRコードが出るので、スマホのカメラで読み取ってください。

これで終わりです。スマホには何も入りません。アカウントも作りません。そして、
何もあなたの家から出ていきません ── ページを配っているのはあなたのPCの中で動いている
小さなWebサーバーで、スマホはそこへ直接つないでいます。

**その代わり、玄関から先には行けません。** そのWi-Fiを出ると、もうアドレスに届きません。
また、同じネットワークにいる他の人にもアドレスは見えます（開くにはQRの中の
アクセスコードが要りますが、扉があること自体は見えます）。

## 2. どこからでも ── Tailscale

カフェからPCに届かせるには、両端を繋ぐ何かが要ります。このプログラムは、そのために
あなたのPCをインターネットに晒すことはしません。それは、あなたが前にいてもいなくても
開きっぱなしになる扉だからです。

[Tailscale](https://tailscale.com/) は別のやり方で解きます。**あなた自身の端末だけ**で
プライベートなネットワークを作り ── PC、スマホ、ノートPC ── それぞれに、そこにしか
存在しないアドレスを与えます。通信は端から端まで暗号化され、2台のあいだを直接流れます。
個人利用は無料で、そして我々のものではありません。運営もしていませんし、中身も見えません。

1. PCとスマホの両方に入れる ──
   [tailscale.com/download](https://tailscale.com/download)
2. **同じアカウント**で両方にサインインする
3. PCで設定をもう一度開く。「スマホ」の欄が **Tailscale（100.x.y.z）が使えます**
   に変わっています
4. さっきと同じようにQRコードを読み取る

このプログラム側の操作は何も変わりません。プライベートなアドレスがあることに気づいて、
そちらを出すようになります。

:::note[アカウントについて、正直に]
このプログラムにアカウントはありませんし、これからも訊きません。Tailscale にはあります
── Google / Microsoft / GitHub / Apple のいずれかでサインインします。どの端末があなたの
ものかを知る必要があるからです。それが、電車から自分のPCに届かせることの正直な対価です。
同じWi-Fiの中だけなら、どちらも払わずに済みます。
:::

## 3. ホーム画面に置く、ポケットで震える

スマホのブラウザが「安全な接続だ」と認めたページにしか、やってくれないことが2つあります。
**アプリのようにホーム画面に置くこと**と、**ページを閉じていても通知を届けること**です。
ここでいう「安全」はHTTPSのことで、いくらプライベートなネットワークでも、素のアドレスは
数に入れてもらえません。

Tailscale なら、本物の証明書を前に立ててくれます。**1行だけ、一度だけ**、端末のどれかの
タブで実行してください。

```
tailscale serve --bg 8787
```

（設定でポートを変えている場合は、その番号にしてください。）プログラムを再起動すると、
「スマホ」の欄が **HTTPSで配信しています** に変わります。QRコードが運ぶアドレスも
`https://自分のPC名.自分のtailnet.ts.net` になります。

### ホーム画面に置く

スマホで画面を開いて、ブラウザの**ホーム画面に追加**を使ってください。アドレスバーの無い
状態で、独自のアイコンから開くようになります。インストールしたアプリと同じ見え方です。

ただし、そのアイコンが役に立つためには、**ペアリングがブラウザのタブより長生きする**必要が
あります。そうでないと、開いた瞬間に「もう一度ペアリングしてください」と言われ、そのための
QRを読もうとするとブラウザが開いてしまい、アイコンからは永遠に入れません。なので、
「スマホ」設定の**トークン固定**をオンにしているときだけ、この案内が出るようにしています。

その設定には**（危険を承知で）**と書いてあり、これは言葉どおりです。アクセスコードが
変わらなくなり、そのスマホの中に残り続けます。つまり**そのスマホを持っている人は画面を
開けます**。ほかのサービスに「ログインしたままにする」のと同じ取引です。この取引が嫌なら、
ここは飛ばしてください。以降の話はオンにしなくても動きます。

### タブが答えたら通知を受け取る

設定の**通知**で宛先を追加し、種類に**スマホ**を選びます。そのうえで、**スマホ側で**同じ
設定ページを開き、**この端末を登録**を押してください。ブラウザが許可を訊いてくるので、
許可します。

あとは、通知してほしいタブで「応答完了時に通知」をオンにするだけです。届くのはタブの名前と
答えの書き出しで、**タップすると、その答えと入力欄だけの小さなページが開きます**。
「うん、進めて」と返すためにPCの前まで戻らなくて済みます。

Androidとパソコンなら、通知にトークン固定は要りません。要るのはホーム画面の
アイコンだけです。

**iPhone と iPad は順序が逆です。** Appleは、ホーム画面に追加したものにしか通知を
配りません（Safariのタブでは、通知の仕組みそのものが存在しません）。つまりiPhoneでは、
ひとつ上の「ホーム画面に置く」が通知の前提になります ── トークン固定も込みで必要です。
追加したアイコンから開き直してから、登録を押してください。

通知の本文は、**あなたのPCを出る前に、そのスマホ宛に暗号化されています**。運ぶのは
ブラウザメーカーのプッシュ配信サービスですが、運べるだけで中身は読めません。あいだに
我々のアカウントはありません。そもそも我々のサーバーが存在しないからです。

## できないこと

- **PCが起動している必要があります。** ここまでの全部は、プログラムの中で動いている
  Webサーバーです。電源の落ちたPC宛に何かが溜まることはありませんし、あとで届けるために
  あなたのものがどこかに保管されることもありません。
- **我々には何も見えません。** [プライバシーポリシー](/ja/privacy/)をご覧ください。
  短く言えば、見えるものが存在しません。
