## Three steps to a running tab

1. **Unzip it anywhere** — a folder, a USB stick. Nothing is installed, and deleting the
   folder removes it completely.
2. **Run `SHIKISHA-TERM.exe`.** Windows stops you here the first time with **"Windows
   protected your PC"**, offering only a **Don't run** button. **More info → Run anyway**
   gets past it, and it does not come back. That screen is SmartScreen, and it appears
   because the zip carries no certificate — not because anything was found in the file.
3. **Press `[e]`.** The settings screen opens inside the window, and you pick which AI runs
   in which folder. There is no JSON to edit.

From there, [the manual](/manual/) is four pages, and [automation](/automation/) is where
agents start handing work to each other.

To check the bytes you got, run `Get-FileHash .\SHIKISHA-TERM.zip -Algorithm SHA256` and
compare it with
[SHIKISHA-TERM.zip.sha256](https://github.com/styleio/ShikishaTerm/releases/latest/download/SHIKISHA-TERM.zip.sha256),
which the same build wrote.
