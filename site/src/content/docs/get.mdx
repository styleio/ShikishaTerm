## Windows will stop you once. That is expected.

The first time you run it, Windows says **"Windows protected your PC"** and offers only a
**Don't run** button. **More info → Run anyway** gets past it, and you will not see it again.

That screen is SmartScreen, and it appears because the zip carries no code-signing
certificate — not because anything was found in the file. Every release is built in public
by GitHub Actions from a tagged commit.

If you would rather never meet that screen,
[the Microsoft Store copy](https://apps.microsoft.com/detail/9PB8XQVM87Z0) is the same
build, signed by Microsoft, and it updates itself.


Compare it with
[SHIKISHA-TERM.zip.sha256](https://github.com/styleio/ShikishaTerm/releases/latest/download/SHIKISHA-TERM.zip.sha256),
which is written by the same build that made the zip.

## Three steps to a running tab

1. **Unzip it anywhere** — a folder, a USB stick. Nothing is installed, and deleting the
   folder removes it completely.
2. **Run `SHIKISHA-TERM.exe`.** A terminal tab is already there.
3. **Press `[e]`.** The settings screen opens inside the window, and you pick which AI runs
   in which folder. There is no JSON to edit.

From there, [the manual](/manual/) is four pages, and
[automation](/automation/) is where agents start handing work to each other.

## One thing that would help

Making that Windows warning disappear from the zip takes a code-signing certificate.
[SignPath Foundation](https://signpath.org/) issues them to open source projects for free,
and asks for *"a certain verifiable reputation"* first. For a project on GitHub, the most
legible form that takes is stars.

So if this turns out to be useful:
**[star it on GitHub](https://github.com/styleio/ShikishaTerm)**. It takes a second, and it
is the one thing a stranger can do that makes a signed build likelier — for everyone who
downloads the zip after you.
