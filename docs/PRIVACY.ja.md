# プライバシーポリシー

SHIKISHA-TERM は、あなた自身のコンピューターの中だけで動くターミナルです。
サインインするアカウントはなく、背後に私たちのサーバーもなく、解析や利用統計の
送信も一切ありません。**開発者があなたのデータを受け取ることはありません。**
受け取りようがありません — このプログラムには、私たちに何かを報告する仕組みが
存在しないからです。

最終更新: 2026年9月2日

## 手元に残るもの

このプログラムが保存するものは、すべてあなたのディスク上のただのファイルです。
置き場所は、プログラムの隣（ポータブル版）か、`%LOCALAPPDATA%\SHIKISHA-TERM`
（Microsoft Store 版）です。

- 設定・ワークスペース・自動化スクリプト
- 端末に表示された内容、保存した AI 討論の記録
- プログラム自身の動作ログ

いずれもエクスプローラーで読み・バックアップし・削除できます。Store 版を
アンインストールするとプログラム本体は消えます。上記のフォルダは、あなたの
判断でいつでも削除できます。

入力した API キーや Webhook の URL は、同じフォルダに**暗号化して**保存され
（AES-GCM、鍵は Argon2 で導出）、それぞれの宛先のサービスにしか送られません。

## ネットワークを使う場面

あなた自身が設定したときだけです。以下はどれも、設定するまで起こりません。
そして通信先は、あなたが選んだ相手に直接つながります — 私たちを経由しません。

| あなたが設定するもの | 通信先 |
| --- | --- |
| タブで動かす AI コマンドラインツール（Claude Code / Codex / Gemini / Aider ほか） | それらは独立した製品で、それぞれのアカウントとプライバシーポリシーを持ちます。SHIKISHA-TERM はそれらを起動して画面を読むだけで、認証情報を見ることも保存することもありません。 |
| **アシスタントモデル**（自動化を書かせる AI、討論の審判をする AI） | あなたが選んだ提供元へ、あなたが入力した API キーで。例: Anthropic / OpenAI / Google、あるいは手元のマシンで動くローカルモデル。 |
| **スマホからのリモート** | あなた自身のスマホへ、あなた自身のネットワーク越しに。実体はこのマシン上の小さな Web サーバーで、そこに直接つなぎます。[Tailscale](https://tailscale.com/) 経由なら自分の端末だけの専用網で、経路は暗号化されます。私たちを通る通信はありません。 |
| **通知** | あなたが登録した Slack / Telegram の Webhook。 |
| **GitHub** のプルリクエスト表示 | `api.github.com` へ、あなたが登録したトークンで。 |
| あなたが書いた**自動化**の `http.*` | あなたのスクリプトが指定した先。 |
| **更新確認**（ポータブル版のみ） | `api.github.com` へ、起動時に一度だけ、公開されている最新バージョン番号を読みに行きます。送るのはその公開ページの取得要求だけです。Microsoft Store 版はこれを行いません（更新は Store が行うため）。 |

## 収集する情報

ありません。利用統計もクラッシュレポートも識別子もメールアドレスも収集しません。
私たちが運営するサーバーに接続することは一度もありません。そもそも存在しません。

## お子様の利用について

SHIKISHA-TERM はソフトウェア開発のための道具です。子ども向けに作られたもので
はなく、また誰からも — 子どもからも — 情報を収集しません。

## 変更について

このポリシーを変更した場合は <https://shikisha-term.com/ja/privacy/> に新しい
版を掲載し、上の最終更新日を改めます。
