# 手引き

画面に何があるか、キーで何ができるか、どこに何があるか。書いてあるのは出荷時の
姿で、変えたところは設定画面に出ます。

翻訳は同じ場所に `docs/MANUAL.<コード>.md` として置きます。歯車の隣の `?` は、
使っている言語の手引きを開きます。

---

## 1. 画面に何があるか

**INDEX** は盤面です。全タブの一覧と、それぞれが何をしているか、文字1つで選ぶ
メニューが並びます。どこからでも `Ctrl+B 0` で戻れます。

**左の一覧**がタブバーです。上から順に:

- **デスク** — いちばん上の名前。押すと別のデスクに切り替えます。
- **プロジェクト** — プロジェクトごとの見出し（色と名前）と、その下に並ぶ作業フォルダ。
  見出しの `+` で、そのプロジェクトのワークツリー（並行開発）を作ります。▾ でプロジェクト
  ごと畳みます。
- **作業フォルダ** — 見出しの下のカード。状態の点と名前、2行目に乗っているブランチが
  出ます。元のチェックアウトには「プライマリ」の札が付き、ワークツリーはその下に並びます。
  カードの下に、そのフォルダで働くタブが並びます。フォルダのカードもタブも、右クリックの
  **名前を変更**でその場で名前を書き換え（欄から離れると保存）、**編集**で設定のページを開きます。
  **この作業フォルダを外す**は、プライマリを含むどのフォルダでも使えます。フォルダも
  ファイルもそのまま残り、一覧から外れて、そのフォルダのタブは閉じます。作業中のタブが
  あるときは外さず、どのタブかをお知らせします。終わらせるか閉じれば外せます。
  ワークツリーのカードには、いちばん下に赤い**完全削除**があります。フォルダごと削除し、
  リンクは先に解除するのでリンク先は残ります。コピーした git の管理外ファイルも一緒に消えます。
  まだコミットしていない変更があるときは削除しません。確認で「二度と表示しない」を選ぶと
  次からすぐ削除します（戻すときは 設定 > 基本 > ワークツリーの削除）。
- **タブ** — 番号と名前と点。**緑**は作業中、**青**は答え終わり、**黄**はあなたの
  返事待ちです。**緑の輪**は、答え終わったものの、始めた作業がまだ動いている状態です（動かしたままの
  コマンドや、AI が裏で動かす作業役（サブエージェント））。この間も話しかけられます。名前の下に、乗っているブランチ・プルリクエスト・開いているポート、
  その下に、そのタブが最後に言ったことが出ます。ポートはフォルダのカードの2行目にも出ます。
  ポート（`:3000` など）を押すと、右の列に
  「ポート」が出ます。そのフォルダで待ち受けているポートが、プログラム名とタブの名前と一緒に並び、
  行を押すとブラウザタブで開きます（PC では、PC のブラウザで開く・アドレスのコピーもあります）。
  フォルダの右クリック（スマホは長押し）の「ポートを見る」でも出ます。サーバーのフォルダでは
  「サーバーのポートを開く」、MicroVM では「公開 URL」がこの項目で、［問い合わせる］を押したときに
  そのマシンに聞きます。
- INDEX と Issue の下に **PROJECT** の見出しと、その右端の `+`（プロジェクトを追加）。
  いちばん下に歯車（設定）、`?`（このページ）、💡（アイデア）、ハサミ（便利ツール）、🎛️（クイックコマンド）。

**クイックコマンド**は、自分で作るボタンの格子です。🎛️ か `Ctrl+Shift+K` で画面いっぱいに
出ます。ボタンを押すと、見ているタブのフォルダに毎回新しいタブが開きます。コマンドは
新しいシェルタブで実行し、プロンプトは新しく起動した AI に渡します。
フォルダが無いときは、コマンドはホームフォルダで開き（アプリの起動にも使えます）、
プロンプトは送りません。ボタンの下の1行が、押すとどこへ送るかを先に言います。
作る・並べ替える・フォルダにまとめるのは 設定 > クイックコマンド です。
本文に書いた秘密情報の名前は、送るときに、見ているデスクの秘密情報の値に置き換わります。

**真ん中**は見ているタブです。端末か、ブラウザのページか、git パネル。画面を分割
したあとは、各ペインの見出しの ▥ ▤ でさらに割る、✕ でそのペインを閉じる、です。
git パネルの「CI」を開くと、そのコミットのチェックが並びます。チェックを押すと、そのジョブの
ログが読み取り専用のエディタのタブで開きます（エラーがあれば最初のエラーの行を出します）。
まだ実行中のチェックと、ダウンロードできるログを持たないチェックは、そのページをブラウザタブで開きます。
端末に出た URL とファイルのパスは、ポインタを乗せると下線が付きます。押すと開き方の
一覧（ブラウザタブ・その行のエディタ・既定のアプリ・フォルダ）が出ます。Ctrl+クリックは
すぐに開きます（設定 > 基本 > 端末の URL やパスを押したとき）。
プログラムが出した、別のコンピューターのファイルへのリンク（`file://サーバー/共有/...`）は、
この PC のタブからならそのコンピューターの共有フォルダとして開きます。

**真ん中の上**には、見ているフォルダのタブが横に並びます。押すと切り替わり、`+` で
タブを足します。タブの ✕ かホイールクリックで、そのタブを閉じます。✕ は見ているタブと、
マウスを乗せたタブに出ます。AI が作業中か返事待ちのときだけ、止めてよいか確認します。
閉じたタブは、並びの右端の ▾ から開き直せます。AI の会話を名前で再開できる CLI
（Claude Code・Codex）なら、会話ごと戻ります。画面に出ていた文字は戻りません。

**右の列**（タイトルバーの ◨ で出す・しまう）は、見ているタブの横で使うものだけを出します。
AI のタブならファイル・git・会話、端末とエディタならファイル・git、ブラウザのページならコンソール。
フォルダが git の管理下になければ git は出ません。ADR を使うプロジェクトのフォルダには ADR も出ます。選んだものはタブの種類ごとに覚えていて、
ページから AI のタブに戻れば、AI のタブで見ていたものが出ます。ボタンで呼び出したもの（たとえば
すべての会話の検索）は、✕ を押すまで、ほかのタブを見ても列に残ります。

**ファイル**は、作業フォルダの中身です。ファイルを押すと、エディタで開きます。行を右クリック（スマホは長押し）すると、
編集・入力欄にパスを入れる・パスのコピー・名前の変更・複製・削除を選べます。フォルダの行と、一覧の空いたところでは、新しいフォルダと**新しい Markdown** も作れます。
新しい Markdown は、ファイル名を決めて、空の文書かフォルダのテンプレートのどれかを元にして作ります。テンプレートは作業フォルダの
`.shikisha/templates/`（中のフォルダも含む）に置く Markdown のファイルで、リポジトリに入れてチームで使います。一覧には front matter
の `title:` があればその題で、無ければファイル名で出ます。テンプレートの中の `{{title}}`・`{{file}}`・`{{date}}`・`{{time}}` は、新しい
ファイルの題・ファイル名・今日の日付・今の時刻に置き換わります。ほかの `{{…}}` は書いたまま残ります。この PC のフォルダで削除したものはごみ箱に移るので、ごみ箱から元に戻せます。
別のマシンのフォルダで削除したものは元に戻せません。また、中にファイルがあるフォルダは削除できません。

**Markdown のファイル**は、エディタの上の切り替えで3つの見方を選びます。**テキスト**（書いてあるとおりの
ファイル）、**見たまま**（表示されるとおりの形で編集する。見出し・リスト・リンクのボタンと、`/` で表・コード・
図・数式を入れる）、**プレビュー**（表示されるとおりの形で読む。表・チェックリスト・色分けしたコード・Mermaid
の図・KaTeX の数式・フォルダの画像・脚注）。見たまま編集は、編集したところだけを書き換えます。それ以外の書き方・
空行・改行コードは元のまま残ります。見たまま編集で書き方が変わるファイル（HTML や脚注を含むもの）はテキストで
開き、理由を出します。とても大きいファイルも同じで、そのときは「それでも見たままで編集する」ボタンを出します。
**目次**は見出しの一覧を文書の横に出します。Ctrl+F で表示中の文書の文字を探します（見たままでは置き換えも
行います）。リンクは、文書の中の見出し、フォルダのほかのファイル（このエディタで開く）、Web ページ（フォルダの
ブラウザのタブで開く。Ctrl を押しながらだとこの PC のブラウザ）へ、それぞれ開きます。**PDF** は、表示した文書を、画面の配色に
かかわらず白地の明るい配色で、数式・図・画像ごと PDF に保存します。保存先は選びます。スマホでは、スマホの印刷が開くので、プリンターの
一覧から「PDF として保存」を選びます。プレビューの段落を右クリック
（スマホは長押し）すると **AI へのメモを書く** を選べます。メモは段落の下に残り、**AI に渡す** を押すと、すべての
メモを「パス:行」の形で AI のタブの入力欄に入れます。読んでから送ってください。渡したメモは一覧から消えます。

**ADR** は、プロジェクトの決定の記録の一覧です。ADR は、何を決めたか、なぜそう決めたかを書いた短い
Markdown のファイルで、MADR の書式でリポジトリの中に置きます。プロジェクトの設定の「ADR」ページで使うようにした
プロジェクトにだけ出ます（置き場所も同じページで決めます。書き換えなければ `docs/decisions` です）。
一覧の上の検索欄で絞り込みます。検索欄に質問を書いて **AI に聞く** を押すと、アシスタント AI が ADR を元に答え、使った ADR の
番号を示します。**新しい ADR** を押すと、MADR の節か、同じフォルダのテンプレート（`adr-template.md`）の節で
フォームが開きます。**会話から下書きする** を押すと、手前の AI のタブの最近の会話から題と各節を書き、その AI を
「意見を聞いた相手」に入れます。新しい ADR は提案中の状態で保存し、最後の番号の次の番号と、題から作った
ファイル名（日本語の題は日本語のファイル名になります）を付けます。**PR で提案する** は、そのファイルだけをコミットしてプッシュし、
チームで議論するための PR を作ります。保護ブランチにいるときは、先に専用のブランチを作ります。提案は
**承認済みにする** か **却下にする** で決めます。承認済みの ADR は書き換えず、**新しい ADR で置き換える** で
置き換える ADR を書きます。古い ADR は「置き換え済み」になります。誤字だけはエディタで直します。
SHIKISHA-TERM のスキルを入れた AI のタブは、承認済みの ADR に従い、反する作業の前には人に確認します。

**会話**には3つの見方があります。**AIコラボ**は、AI が別の AI に頼んだとき
（あなたが `@` でタブを名指ししたときも、AI が自分から頼んだときも）の、AI どうしのやりとりです。
1人1行の短い一言がチャットのように並び、上の段にはタブごとの顔と、それぞれが今していることが出ます。
出るのは、前に出ている AI のタブが加わった会話で、最初は一番新しい会話です。上の帯から、そのタブが加わった
ほかの会話を選べます。同時に進む2つの会話が混ざることはありません。
一言の下の「頼んだ全文」「返答の全文」を押すと、全文が開きます。一言を押すと印（👍 ❤️ 🎉 👀 ✅ ❓）を
付けられます。カードを押すと、AI が見せたコミット・プルリクエスト・ファイル・ページが開きます。
依頼の中で決まったことは「合意」として出ます。「1文目」の札が付いた一言は、その AI が一言を書かなかった
答えです。AIコラボは、AI が別の AI に頼むと自動で開きます（窓を操作している最中は開きません。スマホでは
表示だけを切り替えます）。自動で開くかどうかと一言の上限は、設定 › AIコラボ で変えられます。
**この会話**は見ているタブの会話、**すべての会話**はすべての会話の検索です。

**入力欄の上の帯**は便利バーです。1回押すと、見ている AI に決まった指示（続けて・
説明・レビュー・修正）を送ります。左端の小さな切替で、帯に何を載せるかを選べます。
決まった指示、自分で作ったアクション、マクロの記録、git、AI によるコマンド提案、です。

ページの上のバーの最後にある**メニュー（⋯）**には、ページ内を検索・ダウンロードと、ページを作る人のための
道具が入ります（道具は、設定のブラウザタブの「操作」で「開発」にチェックを入れると出ます。メニュー自体も
そこで外せます）。スーパーリロード、要素を選んで AI に渡す、
デベロッパーツール、ソースコード、DOM が並びます。「要素を選んで AI に渡す」を押すと、
右の列に「選んだ要素」が出ます。［選ぶ］を押してから、AI に見せたいページの要素を押し、
必要ならそれぞれにメモを書いて［AI に渡す］を押すと、選んだ要素が何か・どこにあるか・
HTML・効いている CSS が、その AI の入力欄に下書きとして入ります。
鍵らしい値と、このアプリが持っている秘密の値は、先に `[hidden]` に置き換え、何件伏せたかをパネルに出します。
「ソースコード」はサーバーが送ってきたままの HTML、「DOM」は今の画面の HTML を、
読むだけのエディタで開きます（保存はできません）。スーパーリロード以外は、ページのタブの
右クリックにも同じものがあります。
ページがコンソールに出したもの（ページ自身のログ、捕まえられなかったエラー、読み込めなかった
ファイル）は、右の列の「コンソール」で読めます。そのページで初めて開いたときから記録します（そのときのページが読み込まれてからの分も含みます）。
種類で絞る・消す・AI に渡す、ができます。
ブラウザの DevTools をすべて使うときは、ページのタブを右クリック（スマホは長押し）して
「隣に DevTools を開く」を選びます。DevTools がページの 1 つとして、画面を分けた隣に開きます。
スマホでも、ほかのページと同じように画面が中継され、同じように操作できます。
ほかのタブに仕事を頼むときは、入力欄で @ を使ってそのタブを名指しします。

**ページ内検索**は、ページを見ているときに **Ctrl+F** を押すと開きます（スマホでは、ページの上の
バーのメニューの「ページ内を検索」で開きます）。設定のブラウザタブの「操作」で選ぶ部品の1つで、外したページでは
Ctrl+F はブラウザ自身の小さな検索窓を開きます。打つそばから一致した所がすべて色付きになり、いま見ている一致は
オレンジになります。**Enter** で次の一致、**Shift+Enter** で前の一致へ移り、**Esc** で閉じます。
F3 と Shift+F3 でも移れます。同じページを窓とスマホで見ているときは、検索も1つです。
ページを移動しても、検索の語は残ります。

**ダウンロード**: ページが保存したファイルは「ダウンロード」フォルダに入り、右の列に
「ダウンロード」の一覧が開きます。ファイルごとに、どこまで届いたかと、保存した場所が出ます。
PC では、開く・フォルダで表示ができます（プログラムはフォルダで表示するだけです）。
スマホでは［この端末に保存］で、そのファイルをスマホに保存できます。
SSH サーバーや MicroVM のフォルダのページで保存したファイルは、そのマシンの `~/Downloads` に入り、
そのフォルダで動く AI がそのまま使えます。一覧にはマシン名と場所が出て、［この PC に保存］で写しをこの PC に持ってこられます。
一覧を閉じたあとは、バーのメニューの「ダウンロード」で開き直せます。

**PDF として保存**: バーのメニューと、ページのタブの右クリックにあります。ページを印刷したときの形
（ページが紙の大きさを決めていなければ A4、背景の色も含む）で、ページの題名を名前にした PDF を、
この PC の「ダウンロード」フォルダに保存します。保存した PDF は、ページが保存したファイルと同じように
「ダウンロード」の一覧に出るので、スマホでは［この端末に保存］でスマホに保存できます。
このアプリがページの上に重ねている表示（案内やペン）は、PDF に入りません。

**いちばん下の入力欄**は、見ているタブへ打つ場所です。スマホでは、ここが唯一の
入力口です。

**最下段の帯**には、いまのデスク名、自動化が ON か、スマホがつながっているか、
ビルド、そして受け渡しと作業中の AI を一斉に止める停止ボタンが並びます。見ているタブの AI が
自分の利用上限について何か言っていれば、その行もここに出ます。押すと消えます。

## 2. キー

接頭キーは `Ctrl+B` です（tmux 風）。キーはすべて設定で変えられるので、`Ctrl+B ?` が
**いま実際に効いているキー**を出します。

接頭キーが要らず、どのアプリからでも使えるキーが2つあります。`Alt+Shift+K` で
クイックコマンド、`Alt+Shift+M` でアイデアが開きます。ほかのアプリを使っているときは、
SHIKISHA-TERM が手前に出てから開きます。Mac では `Ctrl+Alt+K` と `Ctrl+Alt+M`
（Control と Option）です。Mac では Option と Shift と文字のキーで ˛ や Œ などの文字を
入力するので、その組み合わせを避けています。この2つのキーは、設定 > ショートカット の
「どのアプリからでも使えるキー」で変えられます。ほかの操作は、同じ画面の
「SHIKISHA-TERM の中のキー」で操作の横の欄を選び、使いたい組み合わせ（`Ctrl+Shift+D`、
`Alt+F4`、`F5`）を押すと、その操作に自分のキーを付けられます。

数字はタブそのものです。`Ctrl+B 0`〜`9` でその番号のタブに移ります（`0` は INDEX）。

| `Ctrl+B b` | 接頭キーそのものをプログラムに送る |
| `Ctrl+B ?` | この一覧 |
| `Ctrl+B :` | コマンドパレット |
| `Ctrl+B k` / `Alt+Shift+K (Mac: Ctrl+Alt+K)` | クイックコマンド |
| `Ctrl+B m` / `Alt+Shift+M (Mac: Ctrl+Alt+M)` | アイデア |

<!-- /guide -->

INDEX のメニューは文字1つです。`e` 設定、`p` パレット、`f` 作業を探す、`i` スマホ用の
QR コード、`r` 終了したタブを再起動、`w` デスク切替、`t` 通知テスト、
`k` マスターパスワード、`?` ヘルプ。
マスターパスワードを設定すると、アプリは**ロックされた状態**で起動します。パスワードを
入力するまでは、タブも設定も表示されず、自動化のパイプからの呼び出しも受け付けません。
キャンセルはなく、ほかに選べるのは「終了」だけです。単独で動き続ける端末はロックの裏で
動き続け、ロックを解除すると再び表示されます。スマホからも解除できます。ボードのアドレスを
開くと、ボードの代わりにロックの画面が表示されます。パスワードを受け付けるのは、途中で
誰にも読まれない回線（このマシン自身、Tailscale、HTTPS）のときだけです。暗号化されていない
LAN のアドレスでは、入力欄の代わりにその理由を表示します。どちらかで解除すると、両方で
解除されます。
マスターパスワードの設定・変更は、このプログラム自身の窓でだけ行います。画面を別の
プログラムとして動かしているあいだ（設定 > 基本 > 画面と作業）とスマホからは、`k` で
聞きません。変更するときは、その設定を外して起動し直します。

マウスでも操作できます。ホイールでスクロール、Ctrl+ホイールで端末の文字の大きさ、
ドラッグでコピー、右クリックで貼り付け、タブ名クリックで切替。ペインの仕切りは
ドラッグで動かせて、ダブルクリックで半々に戻ります。タブバーは右端をドラッグすれば
幅が変わり、ダブルクリックで既定の幅、左端まで詰めるとしまわれて画面が全部端末に
なります。

## 3. 作業フォルダと枝

左の一覧の**作業フォルダを管理**で、名前・プロジェクト・マシンを検索し、複数のフォルダを操作できます。

- **ピン留め** — プロジェクトと、その中のフォルダを優先表示します。再起動後も保持します。
- **アーカイブ** — 確認後にタブを閉じて通常の一覧から外します。ファイルとタブ設定は残ります。
  表示条件を**アーカイブ済み**にして対象を選び、**復元**すると再び開けます。
- **フォルダを削除** — 選択した対象を確認してから、順番に削除します。確認画面には各フォルダの未コミットの変更と
  未追跡のファイルが並び（開くと変更内容を見られます）、**変更を破棄して削除**を押したときだけ削除します。
  元のチェックアウト・ピン留め中・処理中のフォルダは残します。開いているエディタや別のワークスペースで使用している場合も、理由を一覧に表示します。
- **容量を計測** — 表示中のフォルダをバックグラウンドで調べます。容量が大きい順にも並べ替えられます。
  リンク先を除いた概算で、計測日時と失敗理由を表示します。削除で空く容量とは異なる場合があります。

**PROJECT** の見出しの右端にあるフォルダ＋を押すと、プロジェクトを追加します。この PC の
フォルダを開くか、URL からクローンするか、新しく作るかを選べます。追加したプロジェクトは、
設定 > 基本 > デフォルトのコマンド に書いたもの（PowerShell・コマンドプロンプト・Git Bash。
既定は PowerShell）が開いた状態で始まります。タブを閉じて空になったフォルダは、押すとまたそれが開きます。

**SSH で入るサーバーのプロジェクト**も同じダイアログから足せます。「SSH ホストのプロジェクト」で
名前・ホスト・ユーザー・ポート・鍵ファイルを入れるか、`~/.ssh/config` の別名から埋めます。ホストが
あると、ダイアログの一番上の**場所**でこの PC かホストかを選べます。ホストでは、フォルダを
たどって追加するか、URL からそのホストの上でクローンします。git と端末はホストの上で動きます。

**同じプロジェクトの別ブランチを同時に動かす**には、見出しの `+` を押します。
**ワークツリーを作成する**ダイアログが開きます。

- **プロジェクト** — どのプロジェクトから作るか
- **名前または「作成元」** — 4つのタブで決めます。開いたときの **自動** は何も打ち込みません。
  AIへの依頼内容から名前と概要が付きます（下記）。**GitHub** はそのプロジェクトの Issue と
  プルリクエストを探して選ぶと、名前が付き、作業がその Issue に結び付きます（プルリクエストは
  そのブランチを取ってきます）。**ブランチ**は何から切るかを一覧から選びます。**名前**は
  打ち込みます。打ち込んだ名前はそのまま残り、空のままなら自動になります
- **AI** — 新しいフォルダで何を動かすか。既定は 設定 > AIエージェント > アシスタントAI
- **詳細設定** — AI ごとに1つ作る、置き場所、git が運ばないもの（`.env` や `node_modules`）を
  持って行くか、実行される `git worktree add` の行そのもの

AI のツールがプロジェクトの中に自分用に作る場所（Claude Code の `.claude/worktrees/`・
`.claude/checkpoints/`・`.claude/mailbox/` と、この PC での状態を書いたファイル
`agent-registry.json`・`scheduled_tasks.json` など）は、`.claude` をコピーするときも持っていきません。
アプリが用意している「既定」の規則で、プロジェクトの設定の「ワークツリーの作成ルール」の
「フォルダの中の規則」に並んでいます。持っていきたい場合は、その行を「コピー」に変えてください。
プロジェクトの規則を一度見た後に、新しい版で既定の規則が増えると、その行に「前回の確認より後に追加」と
1回だけ出ます。ダイアログでは、持っていかない場所とその大きさを、コピーする行の下に出します。

**ワークツリーを作成する**（`Ctrl+Enter`）を押すと、プロジェクトの見出しの下に
「作っています…」の行が出て、出来るとその場でフォルダのカードに替わります。行の ✕ で止めると、
作りかけのフォルダと新しいブランチは消えます。失敗したら理由が出て、**もう一度**か**閉じる**を
選べます。作ったフォルダは `~/SHIKISHA-TERM/branches/<プロジェクト>/<名前>` にあります。

**依頼内容から付く名前。** 「自動」がオンの作業フォルダ（その作業フォルダの設定で決めます。
ダイアログで作ったワークツリーは最初からオン）は、そこでAIに送った依頼をもとに、AIが名前と
概要を付けます。最初の依頼のあとすぐ付き、その後はそこのAIが作業を終えたときに付け直します
（10分に1回まで）。送るのは依頼の文だけで、AIの返事は送りません。依頼に貼った長いコードは
省きます。付くまでは一覧にブランチ名が出て、自動で付いた名前は少し暗い色で出ます。一覧で
フォルダにポインタを乗せると名前と概要が出ます。スマホではカードに概要が1行出て、カードを
長押しすると、メニューの一番上に概要の全文が出ます。名前か概要を手で書き換えると自動は
外れます。使うAIは 設定 > AIエージェント > 自動の名前 で選び、デスクごとに 設定 > デスク >
自動の名前 で変えられます（いちばん軽い聞き方で聞くアシスタントAIか、登録したAIプロバイダ）。

ターミナルやほかの道具で作ったワークツリーは、見出しの下に「N 個の見つかったワークツリーを
隠しています」と出ます。開いて**ワークツリーリストに表示**するか、✕ で隠したままにします。

この PC に無いフォルダ（別の PC から持ってきた設定）は一覧でそう言います。押すと、
戻すのに何をするかを示し、言えばそのとおりにします。

## 4. スマホから

設定でスマホからの利用を ON にして、QR コードを読みます。全タブとその状態、返事を
書く欄がスマホに出ます。PC でできることはスマホからもできます。準備の3段階は
[スマホから使う](https://shikisha-term.com/ja/phone/) にあります。

**ページをどちらで描くか。** AI がブラウザのページを開いたとき、この機械で描くか、
つないだ端末（窓やスマホ）で描くかを選べます（設定 > 基本 > ページを描く場所）。既定はこの機械です
——スマホからも見られ、誰もつないでいなくても動き続け、ログインが全端末で1つだからです。
どちらを選んでも**ページの通信はこの機械から出ます**。この機械で立てた `localhost:3000` は、
どちらの側から見ても同じものです。

## 5. サーバーにつなぐ

タブの「種類」で **サーバー（このソフトで接続）** を選び、接続先・ポート・ユーザーを入れて、
パスワードを保存します。パスワードは二度と画面に出ず、`user@host's password:` のような
入力待ちも出ません。開くと、そのサーバーの端末がそのままタブになります。

自動化からは、そのタブの名前を書けばファイルも読み書きできます（`sftp_ls` / `sftp_get` /
`sftp_put` など。[自動化リファレンス](https://shikisha-term.com/ja/automation/)）。

**画面からも同じことができます。** タブを追加して、種類を「サーバーのファイル（SFTP）」にします。
アドレス・入る人・鍵は、種類のすぐ下、そのタブの設定にあります（サーバーの端末とまったく同じ欄です）。
入れると、左にこのPCのフォルダ、右にそのサーバーのフォルダが出ます。選んで「送る」「取り込む」、
右端の `⋯` で新しいフォルダ・名前を変える・消す。スマホでは、上の「この PC / サーバー」で片側ずつ見ます。

**本番と検証を見分ける。** 接続の設定の「このサーバーの名前」に「本番」「検証」などと入れ、色を選びます。
名前はタブではなくサーバーに付くので、同じサーバーにつなぐタブ（端末もファイルも）すべてに、
色の四角と名前の札が出ます。ファイルを消す・名前を変える・置き換えるときの確認にも出ます。
踏み台越しのサーバーは、踏み台ごとに別のサーバーです。「取り消せない操作の前に、この名前の入力を求める」を
入れると、そういう操作はその名前を打つまで実行しません。付けた名前は 設定 > サーバーの名前 に並びます。

**サーバーの鍵が前回と違うときは、つなぎません。** サーバーを入れ直したのなら、
`data/known-hosts.json` からその行を消してください。

**ほかのマシンの AI の設定ファイルには、許可したときだけ書き込みます。** サーバーや MicroVM で AI のタブを
初めて動かすと、そのマシンの AI の設定ファイルに、作業の状態を知らせる設定を1件書き込んでよいかを画面で
聞きます（書き込んだ後のファイルの全文を見てから選べます）。許可しなくてもタブは使えます。そのときの状態は
画面の表示と会話の記録から読みます。あとから外すときは、設定 › ホスト でそのマシンを開き、AI のチェックを外して
保存してください。次にそのマシンにつながったときに、このアプリの1件だけを消します。以前の版が確認せずに
書き込んでいたマシンでは、残すか外すかを一度だけ聞きます。

**アプリが留守のあいだもマシンの AI を動かし続ける。** 設定 ＞ ホスト でそのマシンを開き、SHIKISHA ブリッジを置いてから、「アプリが留守のあいだ」で選びます。選べるのは、SHIKISHA-TERM の終了と一緒に止める、決めた時間だけ動かし続ける、AI が動いているかぎり動かし続ける（サーバーだけ）の 3 つです。動かし続けるを選ぶと、SHIKISHA-TERM を終了しても、この PC の電源が切れても、そのマシンの AI は作業を続けます。SHIKISHA-TERM を次に起動すると、同じ AI の同じ画面に繋ぎ直します。終了するときは、AI を動かしたままにするか、すべて止めるかを聞きます。SHIKISHA-TERM が留守のあいだに AI が SHIKISHA-TERM を呼び出すと、答えを求めない呼び出し（報告・メモ・通知）はそのマシンで預かり、SHIKISHA-TERM が戻ったときに渡します。それ以外の呼び出しは「PC が留守です」とすぐに断られ、SHIKISHA-TERM が戻ったら、そのマシンの設定の画面に一覧で出ます（どのタブが・どのコマンドを・いつ呼んだか。中身は記録しません）。同じ画面に、そのマシンで動いている AI の一覧と、1 つずつ止めるボタンもあります。MicroVM を動かし続けると、選んだ時間の分だけ料金がかかり、E2B の契約で連続して動ける時間を超えては動きません。同じマシンで同じユーザーとして動くタブどうしは、タブごとの許可では区切られません。AI どうしを分けたいときは、マシンを分けてください。

`ssh` コマンドを直接打つタブも今までどおり作れます（種類は「SSH (ssh.exe)」）。

## 9. 困ったとき

- **設定を変えたら起動しなくなった** — プログラムの隣の `Settings.cmd` をダブル
  クリックしてください。設定画面だけが開くので、そこで変更を戻せます。
- **フォルダが「この PC にない」と出る** — 見出しを押してください。取ってくる・
  ブランチを作る、の手順が出て、言えばそのとおりに実行します。
- **作業中のはずなのに何も動かない** — `Ctrl+B r` で会話ごと再起動、`Ctrl+B R` で
  新しい会話から起動し直します。
- **受け渡しが暴走した** — 最下段の停止ボタンか `Ctrl+B x` で、受け渡しを一斉に
  止め、作業中の AI にも中断を送ります（そのタブで押すのと同じ Esc や Ctrl+C。
  どのキーかはプロファイルに書いてあります）。`Ctrl+B a` で ON にするまで
  自動化は止まったままです。
- **何が起きたか知りたい** — プログラムの隣の `logs\hooks.log` に、状態の変化と
  自動化の実行が、起動からの秒数つきで残っています。
- **zip を初めて起動したら Windows の警告が出た** — zip にはコード署名が付いて
  いません（Store 版には付いています）。[理由と、落としたものの確かめ方](https://github.com/styleio/ShikishaTerm/blob/main/SIGNING.md)。

## 10. 更新

起動時に一度と、動いている間は1日に一度、新しい版が出ていないかを見に行きます。
出ていれば、サイドバーに小さな札が一度だけ出ます。札の2つのボタンは何も入れません。
**更新を開く** は 設定 > 更新 へ、**今回はいい** はその版について札をしまうだけです。

版を入れる場所は 設定 > 更新 の1か所だけで、札から来ても自分で来ても同じボタンを
押します。**落として入れる** を押すと、zip を落とし、公開されている SHA256 と署名で
確かめてから、AI が作業中なら終了時と同じ確認をして、ファイルを入れ替えて起動し直し
ます。設定・data・logs・desks・scripts には触りません。新しい版の最初の起動では、
先に設定の写しを取ります。入れ替える前の版は残してあり、同じカードの **戻す** で
戻せます。Store 版では同じボタンが Store に入れさせ、Store が再起動します。

**このPCの端末を動かし続ける。** 設定 > 基本 > **このPCの端末** は、はじめからオンです。
このPCの端末（と中のAI）は、アプリの中ではなく、別のバックグラウンドのプロセスで
動きます。窓を閉じても、アプリを終了しても、更新しても、アプリが異常終了しても止まりません。
次にアプリを起動すると、各タブが同じ端末に画面ごと戻ります。そこのAIが `shikisha`
でアプリに頼むことは、そのとき動いているアプリに届きます。終了するときは、動き続ける
端末の数を確認で示します。止めるには、その確認で［いいえ］（すべての端末と AI を止めて
終了）を選びます。初めてこの形で端末を開いたときに、左の列に一度だけ同じことを知らせる
カードが出ます。

オフにすると、それから開く端末はアプリの中で動き、アプリを終了すると止まります。
オンのときに開いて、まだ動いている端末は、そのまま動き続けます（タブは同じ端末に戻り、
同じAIを2つ動かすことはありません）。設定の欄の下に、まだ動いている数と［止める］が
出ます。タブを再起動すると、アプリの中に移ります。

スリープ防止（設定 > 基本 > スリープ防止）は、アプリを終了した後も、動き続けている
端末に効きます。「AI の作業中だけ」では、終了したときに作業中だったAIの端末が、
10 分間何も表示しなくなるまでです。

Store 版は更新だけが例外で、Store から更新を入れるとバックグラウンドのプロセスも
閉じられ、タブはこの設定が無いときと同じく会話に戻ります。設定の欄にもそう出ます。

何版か飛ばしましたか。最新の版が設定を1版ずつ順に引き継ぐので、間の版を入れる必要は
ありません。
