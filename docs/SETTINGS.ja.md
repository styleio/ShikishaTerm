# 設定

このソフトにある設定を、画面ごとに、設定の一覧と同じ順で並べた事典です。画面に何があるか・キーで何ができるかは手引きにあります。ここにあるのは、一つ一つの項目が何を決めるかです。

## ソフト全体の設定

どのデスクでも同じ設定です。左の一覧のいちばん下の歯車から開きます。

### 基本

タブ幅・連鎖・言語など

- **タブバーの幅** — ピクセル。空欄なら既定の幅です。画面でタブバーの端をドラッグしても変わります（0 でしまう）
- **自動チェーン上限** — AI同士の自動転送が続く回数の上限
- **完了と判断するまで** — 返事が終わったと判断するまでの静止時間（秒）。短いと考えている途中で次のタブへ渡します
- **作業が長引くタブの様子見** — 作業中のタブについて、自動化にもう一度知らせるまでの秒数。空か0なら知らせ直しません。返事が止まったAIに気づくための設定なので、長めにしてください（長考を途中で切るほうが、気づくのが1分遅れるより高くつきます）
- **自動切り替え** — 画面が切り替わるのは、自動化が「見せたい」と指示したときだけです（タブに仕事を渡しただけでは切り替わりません）。自分で画面を動かした直後は数秒切り替わらず、設定画面を開いている間も切り替わりません
- **起動時の画面** — 番号ではなく名前で覚えるので、並べ替えても追加しても同じ場所に戻ります。切ると常に先頭から始まります。
- **ワークツリーの削除** — 切ると、左の一覧の右クリックで「完全削除」を押したとき、確認を出さずにすぐ削除します。
- **✕ボタンの動き** — AIは作業を続け、スマホもつながったままです。窓を戻すには通知領域のアイコンをクリックします。終了するにはそのアイコンを右クリックして「終了」を選ぶか、Ctrl+B q を押します。切ると、窓を閉じたときに終了します。どちらでも、作業中のタブがあれば先に確認します。
- **画面と作業** — このプログラムのメモリはほとんどが画面です。別にして動かすと、画面が落ちても（メモリが足りなくなったときや、異常が起きたとき）タブ・端末・作業中のAIはそのまま続き、画面だけが開き直されます。自分で画面を閉じたときの動きは、上の「✕ボタンの動き」のとおりです。盤面はこのマシンだけに出します。スマホと共有するかどうかは別の設定です。次にこのプログラムを起動したときから有効になります。
- **全画面ツールからのコピー** — tmux・Neovim・fzf など全画面のツールは、ssh 越しも含めてこの方法でコピーします。切ると、その中でのコピーが何も起きなくなります。読み取りは常に禁止なので、他で copy したものがタブの中から見えることはありません
- **端末エンジン** — Windows にも入っていますが、このソフトは自前のものを持ち歩きます。どちらが使われるかで、プログラムの出力が画面に届くまでの経路が決まります。同梱しているのは版を固定して検証したものなので、このPCがどれだけ新しいかに左右されません。古い Windows では、OS側のものがだいぶ遅れていることがあります。
- **デフォルトのコマンド** — プロジェクトを追加したときに開くもの、中身の無いフォルダを押したときに開くものです。Git Bash が無い PC では PowerShell で開きます。
- **アシスタントAI**
- **Yoloモード** — 新しいAIタブで権限チェックをスキップする
- **自動の名前を書くAI** — 「自動」をオンにした作業フォルダの名前と概要、それに続くブランチ名を書きます。デスクごとに別のAIを選べます。AIプロバイダを選ぶのもそちらです。
- **その名前に使うモデル** — 名前1つにかかる費用が、ふつうの回答のごく一部で済みます。付く名前が分かりにくいときは外してください。
- **ブラウザのデータ** — ブラウザのキャッシュとログイン状態の置き場。共有にすると全PCでログインを引き継げますが、Driveの同期負荷が増えます
- **ページを描く場所** — 端末がつながっているときだけ効きます。このマシンで描くと、スマホから見られて、誰もつないでいなくても動き続け、ログインは全端末で1つです。つないだ端末で描くと速くて文字もきれいですが、その端末が居ることが必要で、そのページはその端末からしか見えません。どちらでもページの通信はこのマシンから出るので、ここで開いたポートは両方から同じものに見えます。反映されるのは次に開くページからで、開いているページはそのままです。
- **UA（ブラウザ名）** — サイトから見えるこのブラウザの名前です。空欄のままなら Edge として見えます。「安全でないブラウザです」などと言われてログインさせてもらえないサイトに当たったら、ここに Chrome などの名前を入れると通ることがあります。変えたあとに開いたページから新しい名前になります。タブごとに別の名前を付けることもでき、その場合はタブ側が優先されます。
- **端末のフォント** — 端末を描くフォントと大きさ。端末の上で Ctrl+ホイールでもいつでも変えられ、その値がここに残ります。名前を空にすると既定の組み合わせ（罫線と日本語がそれぞれ1マスに収まるもの）になります。
- **配色** — 端末とその周りの窓の配色。一覧に出るのは、このPCが既に持っている配色です — Windows ターミナルに入っているものと、config/themes フォルダに置いた配色ファイル — なので、普段使っているテーマをその名前のまま選べます。明るい配色を選ぶと窓ごと明るくなります。
- **言語** — 画面の言語。自動はOSに従います。選ぶとOSより優先され、再起動で反映されます（lang/<コード>.json を足せば翻訳を追加できます）

### リモート接続

リモート操作・QR

**スマホから使う**

- **有効にする** — 外出先やスマホから、状況の確認と指示ができるようにする
- **ポート** — ふつうは変更不要です
- **パスワード** — 任意の第二関門。通知に載るURL(トークン)だけでは開けなくなります。空なら無し(自己責任)。保存で即反映(既存の接続は切れます)
- **トークン固定** — オンにすると下の文字列がトークンになり、スマホ側はURLに残したまま端末に記憶します(ブックマーク可・タブが消えてもQR不要)。切断ボタンは画面も操作もその場で止めますが、トークンは変わらないので、その端末はリンクを開き直せば戻れます。完全に締め出したい時はこの文字列を書き換えてください。config.json に平文で入ります。パスワードとの併用を推奨
- **この盤面の鍵を持っている端末**
- **Tailscale** — このアドレスに届くのは自分の端末だけです。外出先からでも使えて、いちばん安全です
- **家庭内LAN** — 同じWi-Fiにいる人なら、このリンクで操作できます。自宅なら問題ありませんが、カフェや社内の回線では避けてください
- **このPC内のみ** — このアドレスはPCの内側にしかありません。スマホからは届きません
- **インターネットに公開** — 外部から届くアドレスです。リンクを手に入れた人は誰でもこのPCを操作できます

### タブ操作

🎯で別タブを操作する上限

**タブを操作（🎯）**

- **最大ターン数**
- **最大秒数**
- **最大出力量**
- **上限に達したら** — 「続行する」は予算をリセットし、操作役AIの完了判断に任せます。operateが頻繁に止まって困る場合はこちら。
- **描画待ち(ms)** — 各アクション後、ページの変化が止まるまで（最大この時間）待ってから読みます。0＝待たない。
- **実行前に確認** — ブレーキ：実行前に、ページ上のボタンであなたの承認を待ちます。承認しなければ保留します。

## ショートカット

出荷時のキーです。変えたものは設定の「ショートカット」にあります。

- `Ctrl+B q` — 終了
- `Ctrl+B n` — 次のタブ
- `Ctrl+B p` — 前のタブ
- `Ctrl+B t` — タブを追加
- `Ctrl+B &` — このタブを閉じる（AIが作業中なら確認します）
- `Ctrl+B T` — 最後に閉じたタブを開き直す
- `Ctrl+B r` — このタブを会話ごと再開
- `Ctrl+B R` — このタブを最初から起動し直す
- `Ctrl+B % / Ctrl+B |` — 画面を横に割る
- `Ctrl+B " / Ctrl+B -` — 画面を縦に割る
- `Ctrl+B o` — 次のペインへ
- `Ctrl+B X` — このペインを閉じる（タブは動いたまま）
- `Ctrl+B =` — 仕切りを半々に戻す
- `Ctrl+B s` — タブバーをしまう・出す
- `Ctrl+B g` — 変更したファイルを右に出す・しまう
- `Ctrl+B <` — 仕切りを左・上へ
- `Ctrl+B >` — 仕切りを右・下へ
- `Ctrl+B w` — デスク一覧
- `Ctrl+B W` — 次のデスク
- `Ctrl+B [` — コピーモード（/ で検索、n・N で次と前）
- `Ctrl+B c` — 直近の回答をコピー
- `Ctrl+B l` — 入力をロック
- `Ctrl+B a` — 自動化のON/OFF
- `Ctrl+B x` — 緊急停止
- `Ctrl+B b` — 接頭キーそのものをプログラムに送る
- `Ctrl+B ?` — この一覧
- `Ctrl+B :` — コマンドパレット
- `Ctrl+B k / Alt+Shift+K` — クイックコマンド
- `Ctrl+B m / Alt+Shift+M` — アイデア
