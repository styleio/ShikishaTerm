# ShikishaTerm-AI

Claude Code / Codex / Gemini などの**ターミナルで動くAIを、複数まとめて操作・監視・連携**させる
Windows向けのポータブルツールです。SSHやDocker、WSLの中のAIも同じように扱えます。

インストール不要・管理者権限不要。フォルダごとUSBメモリやGoogle Driveに置いて持ち運べます。

## 使いはじめ

1. `Shikisha-Term-AI.exe` を起動します
2. 設定がまだ無ければ、画面に「`[e]` で設定画面が開きます」と表示されます
3. ブラウザで開いた設定画面で、動かすAIと作業フォルダを決めます

設定だけを開きたいときは **`設定を開く.cmd`** をダブルクリックしてください
（`Shikisha-Term-AI.exe --settings` と同じです）。設定を壊して本体が起動しなくなったときの
復旧にも使えます。

## 主な機能

- **複数AIのタブ管理** — 各タブの状態（処理中 / 完了 / 確認待ち）を色とスピナーで一覧表示
- **ワークスペース** — プロジェクトごとにタブ構成を切り替え（仮想デスクトップのような感覚）
- **自動化** — 「応答が完了したら別のタブへ渡す」「確認には自動で答える」等を
  イベント単位で設定。日本語で指示してAIにコードを書いてもらうこともできます
- **暴走対策** — 自動転送の連鎖回数に上限、緊急停止、入力ロック
- **通知** — 作業完了をSlack / Telegramへ
- **PuTTY相当の接続設定** — ポート・鍵・ポート転送・踏み台などをGUIで設定
- セッションログ、文字コード（Shift_JIS等）、日本語入力、マウス操作に対応

## 操作

プレフィックスキーは `Ctrl+B` です（tmux風）。`Ctrl+B ?` でヘルプが開きます。

| キー | 動作 |
|---|---|
| `Ctrl+B q` | 終了 |
| `Ctrl+B 0`〜`9` | タブ切替（0 = INDEX） |
| `Ctrl+B w` / `W` | ワークスペース一覧 / 次へ |
| `Ctrl+B l` | 入力ロック切替 |
| `Ctrl+B r` | タブの再起動 |
| `Ctrl+B [` | コピーモード（`c` で最新の応答をコピー） |
| `Ctrl+B a` / `x` | 自動化のON/OFF / 緊急停止 |

マウスでも操作できます（ホイールでスクロール、ドラッグでコピー、右クリックで貼り付け、
タブ名クリックで切替）。

## フォルダ構成

```
Shikisha-Term-AI.exe   アプリ本体
設定を開く.cmd          設定画面だけを開く
config.json            全体設定 + ワークスペース一覧
secrets.json           通知先やトークン（暗号化可・共有厳禁）
workspaces/            ワークスペース定義（プロジェクト単位で配布できます）
profiles/              AIごとの状態検出ルール
scripts/               自動化スクリプト
logs/                  セッションログ・自動化のログ
docs/AUTOMATION.md     自動化の書き方
```

`config.example.json` などをコピーして使ってください。

## ビルド

```
cargo build --release
```

Rust（MSVC）が必要です。生成物は単一の実行ファイルで、追加のランタイムは要りません。
